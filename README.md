# Onyi.ng

Starter scaffold for the Onyi.ng MVP based on the repository structure described in the project documentation.

## What this repo now contains

- `src/components/` reusable UI building blocks
- `src/pages/` route-level screens for the marketing site and product areas
- `src/hooks/` custom hooks
- `src/lib/` environment, Supabase, and encryption helpers
- `src/store/` Zustand app state
- `src/styles/` global styles
- `supabase/migrations/` initial database schema
- `supabase/functions/` placeholder notes for edge functions
- `public/` static assets

## Existing concept assets preserved

- `onyi-landing-v3.jsx` remains untouched as the original landing page concept
- `Onyi-ng-Documentation.docx` remains untouched as the source brief

## Next step

Install dependencies and start wiring the real landing page and MVP features into this scaffold.
